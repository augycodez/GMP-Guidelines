Clause 5.5 — Precautionary Symbols

5.5 Precautions — Scope & Purpose

Clause 5.5 covers symbols that warn users of hazards, instruct them to consult documentation, or restrict usage to specific conditions. These symbols must appear wherever labelling regulations or risk management (ISO 14971) require a specific warning to be communicated without relying solely on text.

The fundamental design principle of all precautionary symbols is that they must be self-explanatory to the intended user — a clinician or lab technician — with minimal prior training. ISO 15223-1 specifies that each symbol has an exact meaning that manufacturers may not alter.

"The symbols in this part of ISO 15223 shall not be modified in a manner that changes their meaning." — ISO 15223-1:2016, Clause 4.2

General Requirements for Precautionary Symbols

  • Must be sized to remain legible at the viewing distance relevant to the label format
  • Shall not be placed so close together that they become visually confusing
  • Where accompanied by text, the text shall not contradict the symbol's normative meaning
  • Colour is not mandated by ISO 15223-1, but adjacent regulatory standards (IEC 60601-1) may require specific colours for safety-critical symbols

Clause 5.6 — Identification and Reference Symbols

5.6 Overview — Purpose of ID Symbols

Clause 5.6 covers symbols used to present identification and reference information on medical device labels. These are not warnings — they are data carriers. Every ID symbol is paired with an alphanumeric code or number that uniquely identifies some attribute of the device or its manufacturing history.

The regulatory significance of these symbols has increased dramatically since the introduction of the Unique Device Identification (UDI) systems — EU MDR Article 27, FDA 21 CFR Part 830, and the IMDRF UDI Guidance — which require structured data in machine-readable and human-readable formats on labels.

"The purpose of identification symbols is to enable unambiguous identification of the device or its production context at any point in the supply chain." — ISO 15223-1:2016 interpretive commentary

Key Principle: Symbol Precedes Code

For every Category 5.6 symbol, the symbol appears to the left of or above the corresponding code/number. The symbol tells readers what type of identifier follows; the code itself is the actual identifier. This two-part system is fundamental to UDI label architecture.

Annex A (Informative) — Examples of Symbol Use on Medical Device Labels

Annex A — Purpose and Scope

Annex A of ISO 15223-1:2016 is informative (not normative) and provides representative examples showing how symbols from Clauses 5.1–5.6 are combined on actual medical device labels. The annex illustrates three key scenarios:

  1. Single-use sterile device label — a prefilled syringe outer carton
  2. Sterile pack label — a sterile drape or pouch with multiple attributes
  3. IVD kit label — a diagnostic kit with specimen handling warnings

The examples demonstrate that symbols should be grouped logically — precautionary symbols together, identification symbols together — and that the symbol always precedes its associated alphanumeric data element.

Annex B (Informative) — Use of General Prohibition and Negation Symbols

Annex B — Constructing Compound Symbols

Annex B of ISO 15223-1:2016 explains how to construct compound symbols that express "do not" or "not [attribute]" by combining a base symbol with one of two negation overlays:

Negation Method 1: Prohibition Circle (ISO 7000-1641)

A red circle with a red diagonal bar overlaid on the base symbol, signifying "prohibited" or "do not." The circle must fully enclose the base symbol; the diagonal bar runs from upper-left to lower-right at approximately 45°.

Negation Method 2: General Negation Line

A diagonal line without the circle — used when the circular prohibition symbol is too visually complex for small label formats. Less emphatic than the full prohibition circle.

Standard Compound Symbols from Annex B

Annex B Design Rules

  • The prohibition circle colour: red (Pantone 485 C or equivalent)
  • The base symbol inside the circle must remain clearly recognisable — do not distort the base symbol to fit
  • The diagonal bar must cross the base symbol's visual centre
  • Minimum size: the compound symbol must meet the same legibility requirement as the base symbol alone

CDMO Label Compliance Checklist

Sterile Injectable Device Label — ISO 15223-1 Compliance Checklist

Use this checklist when reviewing labels for sterile injectable medical devices (prefilled syringes, vials with device components, IV sets) intended for global markets. Each item maps to a specific ISO 15223-1 clause or related regulatory requirement.

Category A — Identification Symbols (5.6) — UDI Required

  • REF symbol followed by device model/catalogue number is present and correct
  • LOT symbol followed by batch code is present — format consistent with QMS batch numbering SOP
  • If implantable or reusable: SN symbol followed by unique serial number is present
  • QTY symbol shows correct count if package contains multiple units
  • If IVD: IVD symbol is present in a prominent location
  • GMDN code is included (mandatory for EUDAMED/EU; recommended for other markets)
  • GS1 DataMatrix or barcode encodes correct GTIN (01), LOT (10), SN (21), Expiry (17)
  • Human-readable text accompanies all machine-readable codes

Category B — Precautionary Symbols (5.5)

  • Caution triangle (ISO 7000-0434) or IFU book symbol is present if hazards or detailed instructions exist
  • Biohazard symbol present if device contacts blood/body fluids or contains human-derived materials
  • LATEX symbol present if any component contains natural rubber latex (FDA mandatory)
  • Non-Pyrogenic symbol present if device is tested non-pyrogenic (IV route required)
  • Rx Only symbol present if device requires physician prescription (US/EU Class II+)

Category C — Sterility Symbols (5.2)

  • STERILE symbol present with correct sterilization method identifier (EO/R/STEAM/ASEPTIC)
  • Single Use / Do Not Reuse symbol present on all single-use devices
  • Do Not Re-sterilize symbol present where re-sterilization by user is prohibited
  • Use-by date (ISO 7000-1424) present in YYYY-MM-DD or YYYY-MM format
  • Date of manufacture (ISO 7000-1570) present if required by destination market

（）

Category D — Manufacturer / Regulatory (5.4)

  • Manufacturer symbol (factory icon) followed by manufacturer's full name and address
  • If not manufactured in EU: EC REP symbol and authorised representative's name/address
  • If not manufactured in US: US agent contact information
  • CE marking (if applicable) with notified body number

Category E — Environmental / Storage (5.1)

  • Temperature range symbol present if storage temperature is not ambient (2–8°C refrigerated; frozen)
  • Humidity limits symbol if product is moisture-sensitive
  • Fragile / Handle with Care symbol if applicable
  • Keep Dry symbol if moisture protection is critical
  • Keep Away from Light symbol for photosensitive products

Category F — Annex B Negation Symbols

  • Do Not Reuse: prohibition circle correctly overlaid on base symbol; circle is red
  • Not Sterile: if device is sold non-sterile, symbol or text "NON-STERILE" is present
  • Do Not Use if Package Damaged: present on all sterile single-use devices
  • Non-Latex (if claimed): appropriate symbol or text claim present
